How a mod gets made

Idea, code, test, repeat

STEP 1

I think of the thing

Usually while I'm already playing. "What if slimes glowed?" That's the whole start of it.

STEP 2

We write the code

I tell Claude what it should do and we build it piece by piece. I decide how it works. Claude helps me say it in Java.

STEP 3

I load it and play

Into the game it goes. Something is always wrong the first time, so we fix it and try again.

STEP 4

Another green block

When it works, the day turns green on the wall. Then I start thinking about tomorrow's mod.
